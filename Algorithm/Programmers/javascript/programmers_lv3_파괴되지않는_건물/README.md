# 풀이

이 문제는 누적합(Prefix Sum) 기법을 활용하여 해결하는 문제이다.

## 접근 방법

1. 2차원 배열에서의 누적합을 활용하여 시간복잡도를 개선한다.
2. 각 스킬의 효과를 직접 적용하는 대신, 변화량을 저장하는 별도의 배열을 만든다.

## 구현 단계

1. **변화량 배열 초기화**

   - board보다 가로, 세로가 1씩 큰 배열을 생성한다.
   - 이는 경계 처리를 쉽게 하기 위함이다.

2. **스킬 효과 기록**

   - 각 스킬에 대해 영향을 받는 영역의 꼭지점들에 변화량을 기록한다.
   - 공격(type=1)은 음수, 회복(type=2)은 양수로 처리한다.
   - 영역의 시작점 (r1,c1)에 변화량을 더한다.
   - 영역의 경계에서 반대 부호의 값을 기록하여 누적합 계산 시 영역 밖으로 효과가 퍼지지 않도록 한다.

3. **누적합 계산**

   - 가로 방향으로 먼저 누적합을 계산한다.
   - 이어서 세로 방향으로 누적합을 계산한다.
   - 이렇게 하면 각 칸에 최종적으로 적용되어야 할 변화량이 계산된다.

4. **결과 계산**
   - 원래 board의 값에 계산된 변화량을 더한다.
   - 값이 0보다 큰 칸의 개수를 세어 반환한다.

## 시간 복잡도

- N: board의 행 크기
- M: board의 열 크기
- K: 스킬의 개수

전체 시간 복잡도는 O(K + N\*M)이다.

- 스킬 적용: O(K)
- 누적합 계산: O(N\*M)
- 결과 계산: O(N\*M)
